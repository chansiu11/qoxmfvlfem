# Host practice cheats
The settings panel is visible only to the host and actions require an active match. Healing, refill, invulnerability, infinite ammo and bot pause work across modes. Heavy shield refill, 9000 credits and +30 round seconds are general-mode actions. Personal effects apply only to the local host entity; pause affects all bots. These actions are never accepted as network messages. Existing host snapshots propagate HP, shield, economy and round time. Death is not undone by healing. Toggle states reset on return to the room. Invulnerability prevents host bullet damage before shield consumption and battle damage before downing. Infinite ammo preserves weapon cooldown and semi-auto trigger rules.

Round-end controls let the host select attacker or defender victory in general mode, including preparation. They use normal scoring, economy and end-of-round flow; repeated clicks during end/finished do nothing. Projectiles and held objective input are cleared. At the winning score the match finishes normally.
